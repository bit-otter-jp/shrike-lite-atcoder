# ABC471E AtCoder コードテスト用入力レポート

作成・検証日: 2026-08-18 (JST)

## 結果

AtCoder のコードテスト欄へ貼り付けるため、最大の `N=200000` を保ったまま
500,000 bytes 未満に収めた決定的入力を作成した。

```text
file    = abc471e_code_test.in
N       = 200000
K       = 100000
size    = 401672 bytes
sha256  = 1ed80be11d579b6d34e3e382d88a0bc61125ee34d04ce1983b548d40fafea73c
answer  = 379620342
```

実ファイルのサイズは上限より 98,328 bytes 小さい。ファイルは ASCII、改行は LF
で生成しており、通常の 2 行の AtCoder 入力形式になっている。

## Ai の生成規則

添字 `i=0,1,...,199999` を使い、次の規則で `A[i]` を決める。乱数は使用しない。

```text
large = [998244352, 998244353, 998244354, 1000000000]

if i mod 997 == 0:
    A[i] = large[(i / 997) mod 4]   # このとき i/997 は整数
else:
    A[i] = 1 + (i mod 3)
```

値ごとの出現回数は次のとおりで、指定された全 7 値を含み、すべて公式制約
`1 <= Ai <= 10^9` 内である。

| 値 | 出現回数 |
|---:|---:|
| 1 | 66,600 |
| 2 | 66,600 |
| 3 | 66,599 |
| 998244352 (`MOD-1`) | 51 |
| 998244353 (`MOD`) | 50 |
| 998244354 (`MOD+1`) | 50 |
| 1000000000 | 50 |

入力の再生成には次を使用する。

```powershell
python make_code_test_case.py
```

生成スクリプトは ASCII byte 列を作ってから、書き込まれた実ファイルを読み戻し、
サイズ、SHA-256、必須値の存在を検査する。

## 期待値

`make_code_test_case.py` の独立 Python 実装で、Python の多倍長整数と `math.comb`
を使用して計算した。

1. `sum(Ai^2)` を直接計算する。
2. 走査済み要素の整数和を使い、全非順序対の積 `sum(i<j, Ai*Aj)` を直接加算する。
3. 二乗項には `C(N-1,K-1)`、対の積には `2*C(N-2,K-2)` を掛ける。
4. 最後に `998244353` で剰余を取る。

さらに、全整数和の二乗から二乗項を引く別表現でも同じ値になることを assert した。

```text
EXPECTED_ANSWER = 379620342
```

## ローカル Icarus 最終確認

既存の `abc471e.v` は変更せず、指定された条件でコンパイルした。

```powershell

vvp abc471e.out < abc471e_code_test.in
```

環境は Icarus Verilog 12.0 (devel),
`s20150603-1539-g2693dd32b`。実行は Windows の `cmd.exe` から入力・出力を
リダイレクトし、プロセス開始から終了までをストップウォッチで測定した。

| 確認項目 | 結果 |
