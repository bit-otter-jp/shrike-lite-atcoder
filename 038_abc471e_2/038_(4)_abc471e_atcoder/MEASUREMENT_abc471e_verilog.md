# ABC471E Verilog 最大ケース測定

測定日: 2026-08-18 (JST)

## 結論

`N=200000, K=100000` の最大規模入力を 3 回実行した。最終版は全実行で期待値
`762975326` と一致し、実時間は 1.381084～1.408911 秒、Peak Working Set は
9.266～9.289 MiB だった。

ABC471E の制限は 2 秒、1024 MiB である。手元の測定では制限内だが、AtCoder
本番環境とハードウェアおよび OS が異なるため、時間値をそのまま本番値とみなす
ことはできない。

## 測定環境

| 項目 | 値 |
|---|---|
| OS | Microsoft Windows NT 10.0.26200.0, x64 |
| CPU | Intel64 Family 6 Model 154 Stepping 3, 20 logical processors |
| Icarus Verilog | 12.0 (devel), s20150603-1539-g2693dd32b |
| Python | 3.13.1 |
| PowerShell | 5.1.26100.8875 |

コンパイル条件:

```powershell
iverilog -g2012 -Wall -s main -o abc471e.out abc471e.v
```

実行対象は `vvp abc471e.out` のプロセスである。ストップウォッチはプロセス開始直前
から終了までを測り、標準入力をパイプへコピーする時間も含めた。Peak Working Set
は実行中に Windows の `PeakWorkingSet64` を 1 ms 間隔で取得した。標準出力と
標準エラーは別々に回収した。

## 最大ケース

入力は `test_abc471e.py` の `make_max_values` で決定的に生成した。

```text
N = 200000
K = 100000
Ai = ((i * 1000003 + 123456789) mod 1000000000) + 1
i = 0, 1, ..., N-1
```

生成した入力ファイルのサイズは 1,977,794 bytes だった。再生成コマンド:

```powershell
python test_abc471e.py --skip-compile --random-cases 0 --write-max-case max_case.in
```

期待値は Python 側で次の別実装により求めた。

- 各 `Ai^2` が現れる回数を `C(N-1,K-1)` として数える。
- 各非順序対 `Ai*Aj` をストリーミングで合計し、現れる回数
  `2*C(N-2,K-2)` を掛ける。
- 組合せ係数は Python の `math.comb` で計算する。

期待値は `762975326` である。小規模テストの期待値はこの方法ではなく、K 要素の
全組合せを列挙して各和を実際に二乗する独立 oracle で確認した。

## Baseline 測定

Baseline は各入力値について、値の縮約、prefix sum、square sum の更新で計 3 回の
剰余演算を行う版である。

| Run | 実時間 (秒) | Peak Working Set (bytes) | MiB | 出力 | 正否 |
|---:|---:|---:|---:|---:|:---:|
| 1 | 1.488901 | 9,699,328 | 9.250 | 762975326 | OK |
| 2 | 1.537566 | 9,773,056 | 9.320 | 762975326 | OK |
| 3 | 1.530867 | 9,707,520 | 9.258 | 762975326 | OK |

平均実時間は 1.519111 秒だった。2 秒制限に対する余裕を増やすため、単純な剰余
演算削減を行った。

## 最終版測定

`Ai <= 10^9 < 2*MOD` と、更新前の prefix sum が常に `MOD` 未満であることを利用し、
値の縮約と prefix sum の縮約を `%` から条件付き減算へ変更した。square sum だけは
64 bit のオーバーフローを避けるため、各要素で剰余を取る。

| Run | 実時間 (秒) | Peak Working Set (bytes) | MiB | 出力 | 正否 |
|---:|---:|---:|---:|---:|:---:|
| 1 | 1.381084 | 9,715,712 | 9.266 | 762975326 | OK |
| 2 | 1.408911 | 9,715,712 | 9.266 | 762975326 | OK |
| 3 | 1.381090 | 9,740,288 | 9.289 | 762975326 | OK |

平均実時間は 1.390362 秒で、Baseline 平均比で約 8.5% 短縮した。3 回の幅は
0.027827 秒だった。標準エラーは全実行で空、終了コードはすべて 0 だった。

最終版への変更後、公式サンプル、境界ケース、全組合せ oracle による固定 seed の
ランダム 300 ケースも再実行し、すべて成功した。
