## 解法

`S1 = sum(Ai)`、`S2 = sum(Ai^2)` とする。選んだ K 個の和を二乗すると、各要素の
二乗項と、異なる 2 要素の積の 2 倍に展開できる。

- `Ai^2` を含む選び方は、残り `K-1` 個を選ぶ `C(N-1,K-1)` 通り。
- `2*Ai*Aj` を含む選び方は、残り `K-2` 個を選ぶ `C(N-2,K-2)` 通り。

また、異なる全要素対の積の 2 倍は `S1^2-S2` なので、答えは次である。

```text
C(N-1,K-1) * S2
+ C(N-2,K-2) * (S1^2-S2)
```

すべて `998244353` で剰余を取る。

### 組合せ係数

`C(N-1,K-1)` は `r=min(K-1,N-K)` とし、長さ r の分子積と分母積を作る。分母の
逆元は Fermat の小定理により `denominator^(MOD-2)` を二分累乗で求める。

`K>=2` のときは次の関係で 2 個目の係数を求め、長い積のループを重複させない。

```text
C(N-2,K-2) = C(N-1,K-1) * (K-1) / (N-1)
```

`K=1` では 2 要素項が存在しないため、この係数を 0 とする。これにより `N=1,
K=1` で 0 の逆元を求めることも避けている。

### 整数幅

剰余演算の乗算オペランドは `MOD` 未満であり、積は `10^18` 未満なので signed
64 bit に収まる。`Ai <= 10^9 < 2*MOD` であるため、入力値の縮約は高々 1 回の減算で
よい。配列は使わず、入力を 1 回ストリーミングして `S1`, `S2` を作る。

計算量は `O(N + min(K-1,N-K) + log MOD)`、追加メモリは `O(1)` である。

## 検証

テストは次で実行した。

```powershell
python test_abc471e.py --random-cases 300
```

このコマンドは `iverilog -g2012 -Wall -s main` でコンパイルしてから各ケースを
独立した `vvp` プロセスへ渡す。

### 公式サンプル

| Sample | 入力の要点 | 期待値 | 結果 |

| 1 | `N=3, K=2, A=[1,10,100]` | 22422 | OK |
| 2 | `N=5, K=2, A=[10,10,20,20,20]` | 10600 | OK |

### 境界ケース

9 件を確認した。指示された次の条件をすべて含む。

```text
N=1, K=1
K=1
K=N
Ai=0（公式制約外だが作業指示に従って追加）
Ai=1
Ai=10^9
同じ値が並ぶケース
MOD-1, MOD, MOD+1 を含むケース
```

### 独立ランダムテスト

seed `47100005` で `1<=N<=8`, `1<=K<=N` の 300 件を生成した。Python oracle は
`itertools.combinations` で K 要素部分集合をすべて列挙し、各部分集合について
`sum(selected)**2` を直接加算する。Verilog と同じ集約式を期待値生成に使っていない。

通常の乱数値に加え、`0`, `1`, `MOD-1`, `MOD`, `MOD+1`, `10^9` を高頻度で混ぜた。
全 300 件が一致した。

### 最大ケース

`N=200000, K=100000` の決定的な入力で 3 回測定し、すべて期待値
`762975326` と一致した。Baseline、最適化内容、各実行の時間と Peak Working Set は
`MEASUREMENT_abc471e_verilog.md` に記録した。
