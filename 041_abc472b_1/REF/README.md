# REF

このフォルダは、WORK / CODEX_PROMPTを使って
第41回の実装工程を再実行する場合の参照ファイル配置先です。

第41回の成果物を確認したり、生成済みbitstreamを使って実機動作させるだけなら、
REFは不要です。

実装工程を再現する場合は、GitHub公開リポジトリ内の既存公開物から
必要に応じて次をコピーしてください。

- `abc468b_distRAM`
- `abc468b_pll`
- `atcoder_spi_template_v3`

配置例:

```text
REF/
├─ abc468b_distRAM/
├─ abc468b_pll/
└─ atcoder_spi_template_v3/
```

`abc472a`は第41回実装時の参考にはしましたが、
第41回の実装工程再現に必須ではないため、このREF一覧には含めていません。

各WORK / CODEX_PROMPTに記載された参照先と、
GitHubリポジトリ内の公開フォルダ構成を確認して配置してください。
